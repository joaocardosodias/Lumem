# Modelo 3: Árvore de Decisão para Predição de Falhas em PSDs

## 1. Visão Geral
Modelo de Árvore de Decisão (Scikit-Learn) estruturado nas 5 primeiras fases do CRISP-DM com regras de decisão explícitas e alta transparência.

## 2. Arquivos
- `modelo_3.ipynb`: Notebook executável contendo todo o ciclo de vida: carregamento de alarmes e ordens ZM01, identificação por PSD, engenharia de atributos temporais e validação temporal.
