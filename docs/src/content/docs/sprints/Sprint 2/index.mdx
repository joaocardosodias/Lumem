A **Sprint 2** concentrou-se na construção, treinamento, validação, calibração de hiperparâmetros e explicabilidade dos **Modelos Preditivos de Inteligência Artificial** desenvolvidos pelo Grupo 04 para antecipar ordens de manutenção corretiva emergencial (**ZM01**) nas 526 portas de plataforma (**PSD**) da Linha 4-Amarela do Metrô de São Paulo.

Nesta etapa, consolidamos a **Tabela Mestra Contínua** (*Feature Store*), aplicamos técnicas rigorosas de engenharia de dados e blindagem temporal contra vazamento de dados (*data leakage*), treinamos diferentes famílias de algoritmos de Machine Learning (Árvores de Decisão, Random Forest, XGBoost, LightGBM, CatBoost e Ensembles) e avaliamos os resultados sob as réguas operacionais de engenharia de manutenção.
